# Administración apartada

Este directorio conserva el antiguo panel, sus rutas API y los archivos auxiliares para una posible recuperación futura. Ninguno forma parte de la web estática que se compila desde `app/`.

Si se vuelve a activar el panel, habrá que restaurar sus rutas dentro de `app/`, actualizar las importaciones y usar un despliegue con servidor y almacenamiento persistente.
